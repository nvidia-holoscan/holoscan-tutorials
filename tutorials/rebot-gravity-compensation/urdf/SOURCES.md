# Robot model provenance

`DM/urdf/ReBot_Arm_DM.urdf` is adapted from [Seeed Studio's reBot arm model](https://github.com/Seeed-Projects/reBotArm_control_py/blob/1bcd81b22c182ec257bf04f5746e1e3d556a5f1c/urdf/DM/urdf/ReBot_Arm_DM.urdf).

Source SHA-256: `cd3054edec30b70a3afb2e97eb288ad4943a31c9746f8775703733b64ac0c3cf`.

All joint definitions, link inertias, limits, and frames are preserved. Visual/collision geometry and rendering materials are omitted because the dynamics calculation does not use meshes. The two massless finger joints remain at model-neutral positions when the six arm joints are selected. This asset provides no collision geometry.

No license file was present in the source checkout used for this model.
